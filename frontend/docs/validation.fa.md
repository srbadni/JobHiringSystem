# گزارش اعتبارسنجی

## اجراشده

در محیط Node.js 24.19.0، دستور `npm test` اجرا شد: **۱۰ تست موفق، صفر شکست**.

تست‌ها شامل round-trip متن فارسی و کاراکترهای رزروشدهٔ URL، جلوگیری از شکستن query با `&` و `#`، حذف فیلتر خالی، رفتار پارامترهای تکراری، import خلاف جهت لایه‌ها، import بین sliceهای هم‌لایه، Public API، جداسازی router و بررسی resolve شدن importهای محلی سورس هستند.

اسکن فایل‌های فعلی، importهای قدیمی `features/shared` و `features/widgets` یا استفادهٔ هم‌زمان value/defaultValue در Selectها را نشان نداد. وابستگی‌های package.json و محتویات package-lock.json با ورودی یکسان نگه داشته شده‌اند؛ پکیج جدیدی برای refactor یا تست‌ها اضافه نشده است.

## اجرا نشده / تأیید نشده

نصب آنلاین وابستگی‌ها در این محیط با محدودیت شبکه متوقف شد. تلاش `npm ci --offline --ignore-scripts --no-audit --no-fund` نیز به‌علت نبود بسته در cache با `ENOTCACHED` شکست خورد. در نتیجه `npm run check` نتوانست gate کامل را اجرا کند: ابزار eslint نصب نبود.

بنابراین **lint کامل ESLint، بررسی کامل TypeScript، production build، رندر مرورگر، نبود خطای hydration در مرورگر و اتصال واقعی به بک‌اند تأیید نشده‌اند**. تست policy مستقل از اجرای خود ESLint است و تست URL جایگزین تست یکپارچهٔ Next.js نیست.

طبق AGENTS.md باید راهنمای همان نسخه در node_modules/next/dist/docs بررسی شود. آن پوشه به‌دلیل نبود وابستگی‌ها در دسترس نبود؛ برای تصمیم‌های App Router به مستندات رسمی آنلاین ارجاع داده شد. فایل‌های AGENTS.md و CLAUDE.md تغییر نکرده‌اند.

## بررسی در سیستم شما

```bash
npm ci
npm run check
npm run dev
```

سپس دریافت استان‌ها و دسته‌بندی‌ها، نمایش خطا هنگام قطع بک‌اند و تلاش مجدد، پاک‌کردن انتخاب‌ها، submit با Enter، جستجوی متن فارسی با `C++ & React` و برگشت/جلو رفتن مرورگر را بررسی کنید. مسیر `/jobs/search` باید فیلترها را حفظ کند؛ در این نسخه آگهی واقعی نشان نمی‌دهد.

اگر build هنگام دریافت فونت شکست خورد، دسترسی به Google Fonts را بررسی کنید؛ کد اولیه نیز از next/font/google استفاده می‌کرد. متغیر NEXT_PUBLIC_BASE_URL و CORS بک‌اند باید با محیط اجرا هماهنگ باشند.
