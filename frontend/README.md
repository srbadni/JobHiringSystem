# Job Hiring System frontend

The frontend is a Next.js application organized with Feature-Sliced Design. Read [ARCHITECTURE.md](./ARCHITECTURE.md) before adding a route or slice.

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). The API client defaults to `http://localhost:8000/api/v1`. Override it when needed:

```bash
NEXT_PUBLIC_API_URL=https://example.com/api/v1 npm run dev
```

## Checks

```bash
npm run lint
npm run build
```
