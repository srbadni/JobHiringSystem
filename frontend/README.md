# فرانت‌اند

این پوشه محل اپ مستقل Next.js یا React است. هنوز اپ فرانت‌اند در آن ساخته نشده است.

فایل‌های `package.json`، lockfile جاوااسکریپت، سورس و تنظیمات فرانت‌اند در همین پوشه قرار می‌گیرند. ارتباط با بک‌اند از طریق API انجام می‌شود؛ مسیرهای API در [مستندات مشترک](../docs/api-v1.md) آمده‌اند.

پس از انتخاب ابزار فرانت‌اند، این README را با راهنمای اجرای همان اپ جایگزین کنید.
